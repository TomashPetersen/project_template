# Формализация и проверка идеи

Используй, когда исходную задумку нужно превратить в ограниченную проверяемую идею в [`idea/`](../idea/INDEX.md).

## Готовый prompt

```text
Прочитай AGENTS.md, PROJECT.md и idea/INDEX.md. Помоги оформить идею
<КРАТКОЕ_ОПИСАНИЕ>. Сначала уточни проблему, аудиторию, существующее поведение,
почему сейчас, самый дешевый proof of value и критерий опровержения. Разделяй
FACT, OBSERVATION, HYPOTHESIS и OPINION. Не называй гипотезу подтвержденной без
evidence.

Предложи изменения только в необходимых файлах idea/, начиная с superidea.md,
risks.md, proof-of-value.md и mvp.md. Если данных недостаточно, сформулируй
research-вопросы вместо заполнения пробелов. Перед записью покажи target paths;
после записи покажи diff. Не запускай внешнее исследование, commit или push без
отдельной команды.
```

## Готово, когда

Идею можно опровергнуть ограниченным тестом, а MVP дает один end-to-end результат одной аудитории.
