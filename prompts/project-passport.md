# Интервью для паспорта проекта

Используй для заполнения [`PROJECT.md`](../PROJECT.md) до перехода в `active`.

## Что выяснить

- конкретная проблема, аудитория и контекст;
- проверяемая гипотеза;
- scope-in и scope-out;
- критерии успеха, провала и срок проверки;
- владелец финального решения.

## Готовый prompt

```text
Прочитай AGENTS.md, PROJECT.md и INDEX.md. Проверь текущий repository mode.
Проведи короткое интервью для паспорта проекта <НАЗВАНИЕ>. Задавай вопросы
четырьмя блоками: проблема и аудитория, гипотеза, границы, decision gates.
Не предлагай стек, пока он не нужен для ближайшей проверки. Не выдумывай факты и
помечай мои неподтвержденные предположения как HYPOTHESIS.

После ответов предложи минимальный diff PROJECT.md и проверь все поля activation
gate. Не переводи проект в active без моего отдельного подтверждения. Не меняй
другие домены, не выполняй commit или push.
```

## Готово, когда

У каждого критерия есть наблюдаемый сигнал, а границы исключают очевидное расползание scope.
