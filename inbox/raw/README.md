# RAW неизвестного домена

Имя файла: `YYYY-MM-DD_HH-mm_<slug>.md`.

Эта приемная используется, пока владелец или предметный домен материала не установлен. Файл создается только по прямой просьбе пользователя сохранить материал.

1. Скопировать [`TEMPLATE.md`](TEMPLATE.md).
2. Заполнить обязательные metadata, сохранить только разрешенную часть и классифицировать факты, мнения, гипотезы и цитаты.
3. Установить project-local владельца и перенести устойчивый вывод через central candidate, а не прямое изменение канона.
4. После capture не менять payload; lifecycle обновляется только через frontmatter исходного файла.

Единый обязательный контракт безопасности, privacy, прав, retention, дедупликации, исправления и удаления находится в разделе [`RAW`](../../knowledge/INDEX.md#raw). Этот README определяет только маршрут неизвестного домена и не дублирует policy.
