# Business-RAW

Приемная для исходников, которые однозначно относятся к бизнесу этого проекта: интервью, переписки, исследования, заметки и диктовки.

Если домен неизвестен или материал пересекает несколько зон, использовать [`../../inbox/README.md`](../../inbox/README.md).

## Прием

1. Создать файл `YYYY-MM-DD_HH-mm_<slug>.md` по [`TEMPLATE.md`](TEMPLATE.md).
2. Делать это только по прямой просьбе пользователя сохранить материал.
3. До записи заполнить обязательные metadata, сохранить только разрешенную часть и отделить факты от мнений, гипотез и цитат.
4. При устойчивом выводе создать central candidate, а не менять предметный канон напрямую.
5. После capture не менять payload; lifecycle обновляется только через frontmatter исходного файла.

Единый обязательный контракт безопасности, privacy, прав, retention, дедупликации, исправления и удаления находится в разделе [`RAW`](../../knowledge/INDEX.md#raw). Этот README определяет только business-маршрут и не дублирует policy.
