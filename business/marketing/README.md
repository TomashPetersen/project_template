# Маркетинг

## Что хранить

- позиционирование и проверяемое обещание;
- каналы и причину их выбора;
- воронку и точки потери;
- конкурентов и альтернативы;
- контент-гипотезы и доказательства;
- правила использования бренда и голоса.

## Внешняя Copywriting Mastery

Для задач о рекламном тексте и голосе бренда используй [`logical:shared-mastery/copywriting`](../../mastery/INDEX.md) - единственный зарегистрированный logical route к внешней Copywriting Mastery. Этот identifier допустим только как read-only source ref и не является project-local target.

Внешний метод применяется только read-only и не копируется в проект. Разрешенный project-local результат о конкретном продукте сохраняется в marketing-каноне через [`knowledge/INDEX.md`](../../knowledge/INDEX.md). Изменение самой Copywriting Mastery возвращает `blocked: shared-owner`; неизвестный `logical:shared-mastery/*` также блокируется.
